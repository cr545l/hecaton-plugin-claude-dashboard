# Claude Dashboard

사용량·히트맵·서비스 상태 대시보드와 기존 `dev.hecaton.claude-hook`의 에이전트 상태 기능을 함께 제공하는 Hecaton 플러그인입니다.

- 고정된 상단 탭을 클릭하거나 `1`(대시보드), `2`(에이전트 상태), `3`(활동 기록)으로 화면을 전환합니다. `Tab`으로 다음 화면을 선택할 수 있습니다. 기존 `a` 전환 단축키도 유지합니다.
- 창 테두리를 드래그해 크기를 조절하거나 최대화할 수 있습니다. 작은 창에서는 휠·방향키로 본문을 스크롤하며, 상단 탭은 항상 유지됩니다. 활동 기록은 창 너비에 맞춰 최근 주부터 표시합니다.
- 대시보드를 보거나 최소화한 동안에도 훅 수신, 터미널 상태 배지, 알림은 계속 동작합니다. 최소화 화면은 기존 사용량 표시를 유지합니다.
- Agent State 화면에서 서버·패턴 감지·알림 이벤트·알림 프리셋을 변경할 수 있습니다. 우클릭 메뉴에서 훅 설치와 로그 열기도 가능합니다.
- 기존 `http://127.0.0.1:9218/hook` 주소와 WebSocket 프로토콜을 유지합니다. Claude Code 훅이 최신이면 재설치하지 않습니다.
- 기존 알림 설정을 읽어 사용하며, 이후 변경은 대시보드 데이터 디렉터리의 `agent-state.json`에 저장합니다.

## 적용

기존 **Claude State** (`dev.hecaton.claude-hook`) 플러그인이 실행 중이면 해당 플러그인을 정상적으로 닫고 **Claude Dashboard**를 다시 열어 주세요. 두 플러그인은 동일한 훅 포트를 사용하므로 동시에 실행하지 않습니다. Hecaton 전체를 종료할 필요는 없습니다.

최초 실행 시 필요한 알림 권한을 허용하고, 훅 설치 창이 표시되면 **Install**을 선택합니다. 기존 플러그인 폴더는 원본 보존을 위해 수정하지 않았습니다.

## 언어

한국어와 영어를 지원합니다. Hecaton의 언어 설정을 자동으로 따르며, 실행 중 언어를 바꾸면 화면과 터미널 배지도 즉시 갱신됩니다. 초기 언어는 `initialState.locale`, `HECA_LOCALE`, `i18n.get_locale()` 순으로 확인합니다. 지원하지 않는 언어는 영어로 표시합니다.

화면·메뉴·툴팁·알림·훅 설치 안내를 번역합니다. 진단 로그, 외부 서비스가 반환한 상세 오류·장애 설명, 훅 이벤트 식별자는 원문을 유지하며, 알려진 서비스 상태 문구는 번역합니다.

번역은 `locale/en.json`과 `locale/ko.json`에 있습니다. 새 언어는 같은 키와 `{name}` 자리표시자를 사용한 `locale/<언어>.json`을 추가한 뒤 빌드하면 포함됩니다. 번역이 빠진 항목은 영어로 표시합니다.

## 빌드 및 테스트

`src/dashboard.js`는 대시보드와 화면·입력·종료 처리를, `src/claude-state.js`는 훅 서버와 상태 화면을, `src/i18n.js`는 언어 선택과 표시 폭 계산을 담당합니다. Hecaton은 단일 스크립트를 실행하므로 변경 후 번역까지 포함한 배포 진입점 `main.js`를 생성해야 합니다. 별도 npm 의존성은 없습니다.

```powershell
node scripts/build.cjs
node scripts/build.cjs --check
node --test tests/integration.cjs
```

테스트는 모의 Hecaton 호스트에서 화면 전환, HTTP/WebSocket 이벤트, 알림, 설정 보존과 종료 시 자원 해제를 검증합니다. 실제 Hecaton 화면과 알림 전달은 플러그인을 다시 연 뒤 확인해야 합니다.

설치된 Deno 실행기의 초기화 순서도 별도로 검증할 수 있습니다. 아래 테스트는 별도 Deno 프로세스와 모의 RPC 응답을 사용하며 실행 중인 Hecaton에는 영향을 주지 않습니다.

```powershell
node tests/runner-smoke.cjs <Hecaton 설치 경로>/deno_runner/main.ts
```
